\section{Experimental Protocol and Evaluation Metrics}
\label{sec:exp}

\subsection{Experimental Setup and Hyperparameters}
\label{subsec:exp_setup}
All architectures use an identical streaming pipeline with context window $C=256$ and target horizon $S=64$ ($W = C + S = 320$), trained at stride $16$ and evaluated at stride $1$. Context and target representations ($D=32$) are extracted by the multiscale frequency front-end followed by a 6-block causal dilated TCN (64 filters, kernel size $5$, dilations $\{1,2,4,8,16,32\}$). Multi-statistic temporal pooling (terminal, mean, max, standard deviation, Log-Ricci energy, and first-order total variation) projects features through a linear bottleneck before LayerNorm and dropout ($p=0.20$). Models are trained for $20$ epochs on nominal sequences using AdamW (learning rate $10^{-3} \to 10^{-5}$ via cosine annealing, weight decay $10^{-4}$, batch size $32$), with identical training budgets and zero per-dataset hyperparameter tuning across families.

\paragraph{Held-Out Calibration Protocol and Boundary Isolation}
To evaluate out-of-sample threshold calibration without circularity, each stream's raw nominal sequence $\mathbf{X}_{\text{nom}} \in \mathbb{R}^{T_{\text{nom}} \times K}$ is partitioned chronologically (Fig.~\ref{fig:protocol_and_permutation}, Row~1) into a \emph{training block} $\mathbf{X}_{\text{tr}} = \mathbf{X}_{\text{nom}}[0 : N_{\text{tr}})$ ($N_{\text{tr}} = \lfloor 0.65\, T_{\text{nom}}\rfloor$) and a disjoint \emph{held-out nominal block} $\mathbf{X}_{\text{val}} = \mathbf{X}_{\text{nom}}[N_{\text{tr}} : T_{\text{nom}})$. Standardization parameters and neural weights are fit on $\mathbf{X}_{\text{tr}}$ windows alone, guaranteeing zero raw-observation or window overlap across $N_{\text{tr}}$.

Within $\mathbf{X}_{\text{val}}$ ($N_{\text{val}} = T_{\text{nom}} - N_{\text{tr}}$), sliding windows of length $W = 320$ are constructed strictly inside $\mathbf{X}_{\text{val}}$ (Fig.~\ref{fig:protocol_and_permutation}, Row~2). Under causal trailing attribution, the first $W - 1 = 319$ observations provide context warm-up, yielding $M_{\text{val}} = N_{\text{val}} - W + 1$ valid score timestamps $v[0 : M_{\text{val}})$. Splitting $v$ at midpoint $H = \lfloor M_{\text{val}} / 2 \rfloor$ defines the \emph{nominal calibration block} $v_{\text{cal}} = v[0 : H)$ (used to fit the SPOT threshold at $u=p_{98}, q=10^{-3}$) and the \emph{held-out evaluation block} $v_{\text{hold}} = v[H + S : M_{\text{val}})$, excluding $S=64$ intermediate windows $v[H : H+S)$. Because suspect target windows have length $S=64$, the last calibration target and first evaluation target are $100\%$ disjoint. The first $C=256$ evaluation steps share passive historical context with calibration observations, mirroring online streaming where past nominal history forms context for current predictions. To verify that shared passive context does not bias calibration, we also run a full-window isolation check ($G = W = 320$, excluding $v[H : H+320)$ across the seven streams with $M_{\text{val}}/2 > 420$). Stream-macro causal FPR is virtually unchanged: $0.33\% \to 0.36\%$ for \texttt{Soliton-Reynolds JEPA} and $3.02\% \to 3.24\%$ for \texttt{TS-JEPA}, versus $12.15\% \to 13.97\%$ for TimesNet and $9.05\% \to 9.73\%$ for TranAD. All primary tables use fixed standard SPOT thresholds during testing.

\paragraph{Independent Statistical Units, Multi-Seed Replication, and Equivalence Bounds}
Principal models on the 19 non-GHL streams are evaluated across five random seeds ($\{42, 123, 456, 7, 2024\}$); the 14 GHL streams ($>10^6$ observations each) and ablation controls use three seeds ($\{7, 42, 2024\}$). To prevent pseudoreplication, every statistical test specifies its independent unit explicitly: (i)~seeds are averaged within each stream first to quantify within-stream optimization variance ($\text{SD}_{\text{seed}}$), (ii)~stream-level paired tests treat the telemetry stream ($n=33$ primary or $n=19$ non-GHL) as the unit of analysis, and (iii)~domain-level tests aggregate streams within each hardware platform first and treat the dataset family ($N=7$) as the independent cluster. We employ three statistical tools:
\begin{enumerate}[leftmargin=*, nosep, itemsep=1pt]
    \item \textbf{Paired Wilcoxon signed-rank test and false-discovery-rate adjustment:} The Wilcoxon signed-rank test evaluates whether the median paired difference across streams ($n=33$ or $n=19$) is zero without Gaussian assumptions. We adjust $p$-values across multiple comparisons via the Benjamini--Hochberg false-discovery-rate (FDR) procedure ($q_{\text{FDR}} = 0.05$), report $95\%$ stream-resampled bootstrap confidence intervals (CIs; $2{,}000$ resamples), and cross-check at the dataset-cluster level ($N=7$) via exact sign-flip permutation tests and zero-tuning LODO sensitivity.
    \item \textbf{Two One-Sided Tests (TOST) for fixed-backbone regularizer equivalence:} We use TOST to test whether the multiplicative soliton and manifold gain in (\ref{eq:soliton_score}) alters aggregate Point-F1 relative to the unmodulated multi-horizon whitened envelope $\mathcal{S}_{\text{env}}(t)$ on the identical trained backbone ($n=19$ streams). TOST tests $H_{01}: \mu_1 - \mu_2 \le -\Delta$ ($p_{\text{lower}}$) and $H_{02}: \mu_1 - \mu_2 \ge +\Delta$ ($p_{\text{upper}}$), establishing equivalence when $p_{\text{TOST}} = \max(p_{\text{lower}}, p_{\text{upper}}) < 0.05$ (meaning the $90\%$ paired CI lies inside $[-\Delta, +\Delta]$) across $\Delta \in \{\pm 0.015, \pm 0.020, \pm 0.030\}$ (Table~\ref{tab:ablations}(a)).
    \item \textbf{Distributional tail and drift diagnostics ($\gamma_2$ and $D_{\text{KS}}$):} On nominal windows we measure: (i)~\emph{excess kurtosis} $\gamma_2 = \mathbb{E}[(s - \mu)^4]/\sigma^4 - 3$, distinguishing heavy-tailed \emph{leptokurtic} ($\gamma_2 > 0$) from light-tailed \emph{platykurtic} ($\gamma_2 < 0$) residuals; and (ii)~the two-sample \emph{Kolmogorov--Smirnov (KS) drift statistic} $D_{\text{KS}} = \sup_x |F_{\text{cal}}(x) - F_{\text{hold}}(x)| \in [0, 1]$, quantifying distributional shift between calibration ($F_{\text{cal}}$) and held-out nominal ($F_{\text{hold}}$) blocks.
\end{enumerate}

\subsection{Baseline Architectures, Fairness Checks, and Cohort Structure}
We separate primary multi-seed conclusions (Cohorts 1--2 across 12 neural, linear, and non-parametric arms) from secondary single-seed cross-checks. Two fairness audits verify that reconstructive baseline results under the unified $20$-epoch, $W=320$ pipeline are not artifacts of window length or implementation:
\begin{enumerate}[leftmargin=*, nosep, itemsep=1pt]
    \item \textbf{Native published window lengths} ($5$ streams): Evaluating TranAD ($W=10$) and TimesNet ($W=96$) at their published window sizes raises Point-F1 ($0.164$ and $0.218$), but observation residuals remain severely leptokurtic ($\gamma_2 = 448.3$ and $98.1$ vs.\ $3.1$ for \texttt{TS-JEPA}) with high nominal FPR ($28.4\%$ and $44.1\%$).
    \item \textbf{Secondary 130-stream single-seed cross-check:} Reconstructors replicate their published point-adjusted F1 on SMD and MSL, and Table~\ref{tab:core_benchmark}(d) provides a secondary 130-stream, 11-dataset single-seed comparison against NCAD, DCdetector, and Anomaly Transformer.
\end{enumerate}

\subsection{Cohort Summary and Reproducibility Specifications}
\label{subsec:cohort_repro}
Experiments are organized into five cohorts with distinct statistical roles:
\begin{itemize}[leftmargin=*, nosep, itemsep=1pt]
    \item \textbf{Cohort 1 (33-stream primary multi-seed benchmark):} 19 non-GHL streams (5 seeds) and 14 GHL streams (3 seeds), reported in Tables~\ref{tab:core_benchmark}(a)--(c) and \ref{tab:calibrator_comparison}(a).
    \item \textbf{Cohort 2 (19-stream matched-backbone factorial and operating-curve suite):} 12 controlled arms across 5 seeds, reported in Table~\ref{tab:ablations}(a),(c) and Fig.~\ref{fig:operating_and_horizon}(b).
    \item \textbf{Cohort 3 (6-stream quiet-fault and hybrid-monitor suite):} Six injected single-channel fault types with hybrid sensor monitors (3 seeds), reported in Fig.~\ref{fig:regularizer_and_quiet_fault}.
    \item \textbf{Cohort 4 (5-stream horizon-latency and frequency-shell panels):} Target-horizon sweep ($S \in \{1,4,16,32,64\}$, 3 seeds, matched emission lag $S{-}1$) and dyadic front-end ablation, reported in Fig.~\ref{fig:operating_and_horizon}(a) and Table~\ref{tab:ablations}(b).
    \item \textbf{Cohort 5 (130-stream single-seed baseline screen):} Secondary breadth cross-check across 11 datasets against NCAD, DCdetector, and Anomaly Transformer (Table~\ref{tab:core_benchmark}(d)), treated strictly as auxiliary evidence rather than equivalent to the multi-seed benchmark.
\end{itemize}
At $K=25$ channels, online trainable parameter counts are closely matched across latent and observation-space backbones: $272{,}266$ online parameters for \texttt{TS-JEPA} ($540{,}148$ total including the stop-gradient EMA target encoder), $311{,}658$ online ($618{,}892$ total including the multi-depth tap head and sub-horizon rollout predictor) for \texttt{Soliton-Reynolds JEPA}, $304{,}138$ for matched-encoder \texttt{TCN-ObsPred}, $307{,}402$ for \texttt{TCN-ObsPred-LN}, $648{,}553$ for TimesNet, and $205{,}746$ for TranAD. Non-finite telemetry entries are zero-imputed with channel standard deviations floored at $10^{-2}$. Causal and retrospective buffered scores receive separately fitted thresholds $\tau_{\text{SPOT}}$ fitted strictly within their respective calibration windows $v_{\text{cal}}$ as defined in (\ref{eq:spot_threshold}). All primary multi-seed runs converged under the $20$-epoch schedule on PyTorch 2.4 / CUDA 12.4 (NVIDIA RTX 5090, $0.60\text{--}0.88\,\text{ms}$ per window, $188\,\text{MB}$ of GPU memory); stream manifests, fitted thresholds, and source code are available at \url{https://github.com/quaid281/NCAD}.

\subsection{Multi-Tier Statistical Evaluation Metrics}
\label{subsec:eval_metrics}
To guard against point-adjustment inflation, channel-averaging bias, and threshold gaming \cite{schmidl2022anomaly, kim2022towards}, we evaluate models across three tiers. First, \emph{primary calibration and accuracy outcomes} comprise realized held-out nominal FPR ($\text{FPR}_{\text{hold}}$), out-of-sample calibration error $|\text{FPR}_{\text{hold}} - q|$ relative to design risk $q = 10^{-3}$, unadjusted Point-F1, and threshold-free PR-AUC. Second, \emph{operating characteristics} evaluate event recall across deployable calibration quantiles ($q^*$, Fig.~\ref{fig:operating_and_horizon}(b)) and across post-hoc matched realized test-FPR budgets ($f^* \in \{0.01, 0.05\}$, Table~\ref{tab:ablations}(c)). Third, \emph{secondary operational endpoints} report unweighted Dataset-Macro Point-F1, event recall (fraction of contiguous anomaly segments with $\ge 1$ alarm), mean detection delay $\Delta t$ over detected events, and the constant-alarm baseline $\text{F1}_{\text{all-pos}} = 2\pi/(1+\pi)$ at prevalence $\pi$.
