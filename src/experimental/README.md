# Auxiliary Weight-Space & Phase-Embedding Ablations

This package contains isolated diagnostic modules used in secondary ablations of the 224-dial `SolitonReynoldsJEPAModel` tier:

- `weight_space_programming.py`: Surgical false-positive quenching and zero-data weight-space inspection for multi-horizon circuit-breaker dials.
- `phase_embedding_synthesis.py`: Orthogonal Legendre sub-block phase basis synthesis and structural parametrization.

These modules are not imported by the primary `LaminarJEPALiteModel` training or inference pipeline.
